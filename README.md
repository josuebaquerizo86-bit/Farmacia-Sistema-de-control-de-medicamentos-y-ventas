# FarmaControl — Sistema de Control de Medicamentos y Ventas

Proyecto académico de la asignatura **Introducción a la Ingeniería de Software** (ISO01IS) — Universidad Estatal de Milagro, Facultad Ciencias e Ingeniería, Carrera de Software.

**Grupo 11 — Temática: Farmacia**

## Descripción

FarmaControl es un prototipo web que permite a una farmacia gestionar su inventario de medicamentos y registrar sus ventas, controlando el stock disponible y generando alertas de bajo stock o próximo vencimiento.

## Problemática que resuelve

Las farmacias pequeñas suelen llevar el control de medicamentos y ventas de forma manual, lo que genera pérdida de información, desabastecimiento no detectado a tiempo y dificultad para conocer el estado real del inventario.

## Funcionalidades principales

1. **Gestión de usuarios** — registro, edición y listado de empleados (farmacéuticos y cajeros).
2. **Gestión de medicamentos** — registro, edición y baja de medicamentos con precio, stock y fecha de vencimiento.
3. **Registro de operaciones** — registro de una venta con descuento automático de stock.
4. **Consulta de información** — historial de ventas y stock actual de cada medicamento.
5. **Reporte básico** — estadísticas de ventas, total vendido y medicamentos con bajo stock.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
- Persistencia en `localStorage` del navegador (prototipo sin backend)

## Instalación y ejecución

No requiere instalación de dependencias.

1. Clonar el repositorio:
   ```bash
   git clone <url-del-repositorio>
   ```
2. Entrar a la carpeta `/prototipo`.
3. Abrir el archivo `index.html` en el navegador (doble clic, o clic derecho → "Abrir con" → navegador de su preferencia).

El prototipo carga datos de ejemplo (empleados y medicamentos) la primera vez que se ejecuta.
